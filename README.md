# VR Projects

Canonical repository for the VR Objects library, virtual environments, and mixed-reality experiments.

Source repositories remain unchanged during migration.

## Publishing uploaded GLB objects

The [verified binary upload procedure](docs/BINARY_UPLOAD_METHOD.md) transfers lossless 3D assets through the connected GitHub tools, reconstructs and checksums them using GitHub Actions, and publishes independently linked Quest 3 object pages. A direct GitHub website upload (up to 25 MiB) is a fallback, not a requirement when connected binary transfer succeeds.
