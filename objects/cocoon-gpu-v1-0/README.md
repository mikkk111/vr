# Cocoon GPU V1.0 — experimental Quest 3 port

Source: Yuri Artiukh's Codevember 2026 Day 20, pinned at 902fcb1f492dac4138d72aad16dd85af71ceeda4. The browser fetches the author's original hero source, compressed geometry, neural weights and AVIF textures from upstream. It applies exact-match source patches locally, compiles TypeScript in-browser, and uses the original raw WebGPU lighting, shell and fibre renderer. No copied model binary is stored in this repository.

The initial adaptation is one high-detail hero cocoon, not the nine-cocoon animated installation. The original hero animation and internal lighting are retained. The original camera lens blur is disabled in XR; stereo views use XRGPUBinding, XR-compatible adapter, per-eye matrices and shared Zelda v13 grab engine with a thin XR pose bridge. Transparent coverage is preserved for AR. Quality controls reduce selected fibre counts and framebuffer resolution. This is an experimental port, not yet tested on a physical Quest 3. Individual thread tearing/deformation and haptics are not implemented in V1.0. Runtime depends on the upstream GitHub raw assets and CDN packages. No upstream licence was located; source is linked rather than vendored.
