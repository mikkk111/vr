# Cocoon Lite V1.2
A separate WebGL 2 recovery build using the shared Zelda v13 grab engine and the original hero fibre data at 902fcb1f492dac4138d72aad16dd85af71ceeda4. One stationary cocoon, 12,860 original sampled curves, fixed approximate studio illumination and baked colour/bump texture from 9,000 original wound strands. Shell relief estimated from 18,000 down-fibre roots. Hanging thread is a lightweight procedural approximation. No neural shader inference, HDR offscreen passes, bloom, depth-of-field, compute shaders, animation or quality controls. Trigger adds warm simulated internal illumination; no deformation or tearing. Native WebGPU not used. Source geometry fetched from upstream and decoded once. Physical headset performance and appearance not yet tested.
