# Human Ragdoll V1.6 — posed pickup and dragging

V1.5 tissue solver, contact samples, fitted hulls, 60 kg mass, slider defaults, native Jolt joints and original GLB remain exactly unchanged; V1.6 references the immutable V1.5 secondary.js and fit.json files. A new shared ragdoll-specific Zelda v13 adapter preserves its controls and adds live hit testing, pre-acquisition rebasing and release pose commit. Original shared controller file untouched.

The previous whole-body grip tested a static standing bounds box centred on the original anchor, which is not where the articulated body necessarily lies after a fall. V1.6 checks the current 15 posed hulls for near contact or ray hits, with a current-pose bounding-box aiming fallback. First whole grip recentres the physics coordinate origin on the live hull bounds while preserving world-space pose. Existing 10%–350% linear two-hand resizing and wrist rotations retained. A second grip joins without a separate aim requirement. Ground clearance is checked while whole-gripped (gravity enabled); release commits the actual visible pose, avoiding delayed handle-target drift into floor. Native dynamics resume if already running.

Trigger grabs support close grip-space tracking and remote target rays, with larger pick tolerance and faster target tracking. A mass-sensitive spring uses effective minimum limb-chain mass 2.4 kg; local force bounded. If a grab falls more than 8.5 cm behind the target, progressive whole-body pulling assistance distributes load across pelvis and torso, reaching full assistance at 30 cm. Default total assist limit 1100 N, divided across active controllers; native joints and contacts stay enabled. Heft slider still affects force and whole-object inertia. This is a gameplay force-assist model, not literal measured human handling or force-feedback hardware.

Numerical helper regression: all 15 original hulls pass test ray hits and near-point projection; test rebase world-space vertex invariance within 1.1e-15 m. Default hand spring with 3 cm target error at rest gives 16.39 N including gravity compensation; far horizontal and vertical assist both 1100 N, two-controller assist budget 550 N each. JS syntax and exact V1.5 tissue references checked. These are isolated mathematical tests; native dynamic drag, two-hand transitions, floor resize, live Pages deployment and Quest runtime remain unverified.
