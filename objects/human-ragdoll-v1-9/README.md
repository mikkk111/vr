# Human Ragdoll V1.9 — room-relative startup and gravity repair
Preserves prior character fit, 60 kg mass, joint settings, tissue response, compact 600-triangle table and controller adapter. On first valid XR viewer pose, spawn character 1.35 m forward/0.48 m left, table 1.4 m forward/0.68 m right, both aligned with horizontal headset direction; start gravity automatically. Whole-character release explicitly resumes gravity. While whole-gripped or manually paused, character bodies become kinematic with joints temporarily disabled; the single native Jolt world continues advancing the dynamic table. Table grip remains independent. Character and table retain the same floor and collision world, with tabletop approach guard during whole-body manipulation and a residual table floor penetration guard. Runtime faults report visibly rather than repeatedly pausing and hiding the cause. Native test checks original table geometry, drop, hold/release, resizing and body support. Test status is separate; do not assume Quest validation.

Native regression passed with exact physics engine and compact mesh: tabletop height 0.797 m; held-character drift zero; table settles on floor after dropping and resizing; character movement 1.158 m after release; 184 supported frames in 240-step tabletop drop test. Root cause reproduced: invalid WASM memory destruction during table velocity capture. Replaced with owned reusable buffers. Browser/Quest verification remains outstanding. V1.9.1 also moves table velocity capture out of substep loop to reduce per-frame overhead and snapshots the initial headset transform.
